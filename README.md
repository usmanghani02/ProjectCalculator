Enhanced Calculator - Streamlit App
📝 Description
A feature-rich calculator web application built with Streamlit that supports basic arithmetic operations, square roots, exponents, and more. The calculator includes both button and keyboard input methods.

✨ Features
Basic Operations: Addition (+), Subtraction (−), Multiplication (×), Division (/)

Advanced Functions: Square root (√), Exponents (^), Sign change (±)

Dual Input Methods: Button interface and direct keyboard input

Error Handling: Gracefully handles invalid expressions

Responsive Design: Clean layout that works on different screen sizes

Session State: Maintains calculation history during use
